**AI Reel Generator
**
An AI-powered web app that automatically creates short video reels for TikTok, YouTube Shorts, and Instagram — complete with AI-generated images, voiceovers, and storylines.

** Overview
**
AI Reel Generator combines multiple AI tools to help you generate creative, ready-to-share reels in just a few clicks.
It takes a short idea or topic, writes a story using Gemini API, generates visuals with Stability AI’s Stable Diffusion, and adds realistic audio narration using the Text-to-Speech Unlimited model from Hugging Face.

Built with Next.js and Tailwind CSS, the app offers a clean, modern UI and fast performance.

**How It Works
**
1) Enter a topic or short idea.
2) The app uses Gemini to create a story or script.
3) Stable Diffusion generates matching images for each part of the story.
4) The Hugging Face TTS model converts the story into speech.
5) Everything is combined into a short reel - perfect for TikTok or Youtube Shorts.

**Tech Stack
**
Frontend: Next.js, Tailwind CSS

AI APIs: Gemini API, Stability AI (Stable Diffusion), Hugging Face (Text-to-Speech Unlimited)

Video: FFmpeg or similar backend tools for composition
